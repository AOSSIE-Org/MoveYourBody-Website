MoveYourBody API

Version: 1.0.0

Machine-readable endpoints and documentation for MoveYourBody, the privacy-first, on-device AI fitness app by AOSSIE.

Endpoints

  • /api/info.json — Project metadata (JSON)
  • /openapi.json — OpenAPI 3.0.1 specification
  • /llms.txt — LLMs.txt for AI agents
  • /.well-known/ai-plugin.json — AI Plugin manifest
